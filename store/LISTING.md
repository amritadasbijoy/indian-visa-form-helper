### Description (English)

```
Save time on the Indian visa application for Bangladesh (indianvisa-bangladesh.nic.in). Free to use.

Enter an applicant's details once. The helper then fills every page of the online form for you: personal and passport details, address, family, visa details, references, place of stay, photo and document upload. It works for all Indian missions in Bangladesh (Dhaka, Chattogram, Rajshahi, Sylhet, Khulna) and for Tourist and Medical visas.

WHAT IT DOES
• Free passport scan: drag in a photo or PDF of the passport and the details are filled in for you (name, dates, passport and NID number, parents, spouse, address). Works with phone photos and grey copies.
• Free hotel search by city, with real hotels and their phone numbers, ready to use as the place of stay.
• Saves applicants, hotels, hospitals and references, so families and agencies can reuse them.
• Prepares the photo and PDF documents in the size the site accepts.
• Checks everything before you start, so a captcha is never wasted on an application that would stop half-way.
• Makes the Medical Visa Undertaking form ready to print and sign.
• Keeps a history of Temporary IDs and Application IDs, saves the final application PDF and checks visa status in one click.
• Try it straight away with a made-up example applicant.
• English and Bangla interface.

YOU STAY IN CONTROL
The captcha and the final "Verified and Continue" are never automated: you check the application and submit it yourself. The Additional questions declaration and the document verification box can be ticked for you (Settings, with a countdown and Pause).

PRIVATE BY DESIGN
Your applicants are stored only in your own browser. There is no account and no tracking. The passport scan and hotel search use the Visa Helper server, which reads the image or city and keeps nothing; you can also scan on your own computer only. The optional AI scan is not free: it uses your own AI service and API key, which charges you per scan. Every other feature is free for everyone.

UNOFFICIAL
This is an independent tool. It is not made by or linked to the Government of India, the High Commission of India or IVAC. Always check your application before you submit it.
```

## Privacy tab

**Single purpose:**
```
Fills the Indian visa application form at indianvisa-bangladesh.nic.in with applicant details the user has saved in the extension.
```

**Permission justifications:**

| Permission | Justification |
|---|---|
| storage | Stores the user's applicants, hotels, hospitals, references and settings locally in the browser so they can be reused on every visa form page. |
| unlimitedStorage | Applicant photos and supporting PDF documents (up to 500 KB each, several per applicant) are stored locally and can exceed the default storage limit for families and agencies with many applicants. |
| sidePanel | The helper's main screen (applicants, Start, history) is shown in the side panel next to the visa website. |
| Host permission: indianvisa-bangladesh.nic.in | Content scripts fill the fields of the visa form pages, upload the photo and documents, and show progress on that site only. |
| Host permission: api.anthropic.com | Used only if the user adds their own Anthropic API key, for the optional "Scan with AI" passport reading and "Find hotels" features. |
| Optional host permissions (River AI, OpenAI, OpenRouter, Google Gemini, localhost) | Requested at runtime only when the user sets up their own OpenAI-compatible AI service for the optional AI scan. localhost is for a model running on the user's own computer (Ollama). |

**Are you using remote code?** No, I am not using remote code.
(All JavaScript, including Tesseract OCR and PDF.js, is packaged inside the extension.)

**Data usage – what user data do you collect?** Tick:
- Personally identifiable information: yes (name, address, email, phone, passport and ID numbers; the passport image is read by the server scan)
- Personal communications: no
- Location: no
- Web history: no
- User activity: no
- Website content: yes (the application PDF and status saved from the visa site)
- Health information: tick only for Medical visas (the illness name and hospital letter are entered for the visa form)
- Authentication information: yes (the user's own AI API key, stored locally)
- Financial: no

Note for the form: applicants are stored locally in the browser. The passport image (server scan) and the city name (hotel search) are sent to the developer's server ivh.techistbd.com only to read them and send the result back; nothing is stored there. Agency sync (invited users) stores data encrypted with the user's own password, which the server cannot read.

**Certify all three statements:**
- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

## Test instructions (for the reviewer)

```
The extension fills the official Indian visa application at https://indianvisa-bangladesh.nic.in/visa/ for applicants in Bangladesh.

To try it without submitting anything:
1. Open the side panel (click the extension icon).
2. Settings tab → "Try it with example data" → "Add example applicant" (a made-up applicant, hotel and documents), or Applicants tab → "Tourist applicant" with any made-up details. The free passport scan can be tried with the sample passport image offered in the same card.
3. Start tab: choose the applicant, mission, hotel and dates. The pre-flight check lists anything still missing.
4. Open https://indianvisa-bangladesh.nic.in/visa/ → "Regular Visa Application" and click Start in the side panel. The page is filled; the user types the captcha. Do not submit with made-up data.

The captcha and the final submit are never automated. The free passport scan and hotel search use the developer's server (ivh.techistbd.com), which stores nothing. AI features are optional and need the user's own API key; without a key nothing is sent to any AI service. No login is required.
```
